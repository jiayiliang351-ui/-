# 出片后按病症改

用户说"乱七八糟"时，先问清是哪一种（可以多选），再对症改。每次只改一处，另存新版本。

| 病症 | 最常见的原因 | 先试这个 |
|---|---|---|
| 动作没按顺序发生、走不到目的地、做到一半就变了 | 一段里事件太多；先后关系没写清；提示词是规则清单而不是按时间写的描述 | 删事件，一段只留一条因果链；用 `first … then … as … until …` 按播放顺序写；删掉所有规则段 |
| 动作被跳过、两个镜头被合成一个 | 镜头太密、切点间隔太短 | 文戏每镜至少 1.5 秒、快动作至少 1.0 秒；按戏的类型减镜头数；切点用官方句式 |
| 自己多切了镜头，或者该切没切 | 镜头头不是官方格式；描述里有"cut""insert"之类的词混在动作里 | 只在 `[Shot N] At …` 处切；镜头内不写切换类的词 |
| 穿模、手粘连、多出肢体 | 两人在同一全身画面里精确接触 | 接触只给特写；或拆成接触前、接触后两镜；或停在将触未触 |
| 动作发飘、没重量、像慢动作 | 没写重量和落定；受惊、碰撞没写速度 | 写重量、接触点、落定（见 physics-and-action.md 第 2 节）；写 `in real time`、`a sudden full-body flinch` |
| 脸崩、脸糊 | 快速运动 + 脸在画面里太小；768p 远景 | 推近到胸部以上；动作放慢；用首帧图（I2VA）锁脸 |
| 人物长相、衣服跟上一段不一样 | 纯文生，每段重新长；只靠末帧接力，漂移越积越多；服装没在每段写全 | 定稿图 + Ref2VA（要首帧时用 `[keyframe completion + reference generation]`，首帧和身份图一起挂）；每段 [Shot 1] 完整写服装 |
| 多出来一个人 | 没说在场人数；背景描述里有"人群""同事们" | [Shot 1] 写 `Only the two of them are in the room.`（或先写空的空间再写人数）；背景只写物件 |
| 台词配错了脸（串词） | 两个相像的人同一段都说话 | 按说话人拆成单人段，用接力连起来 |
| 嘴一直在动、没说话时也在动 | 画内说话人说完没写收口；听者的脸在画里，却没写嘴闭着 | 说完写收口（`Exactly as his voice stops, his lips meet …, and his jaw ceases speaking motion; …`，或紧接一个动作）；看得见脸的听者把闭嘴并进反应句（`…, his lips pressed together`）；切到听者时改用画外音句；单人说话的段可加单声源句 |
| 台词说不全、尾字被吞、语速飞快 | 台词超预算；台词中间插了太多小动作 | 删字到预算内；先砍插在台词中间的分心动作 |
| 声音是乱语、杂音 | 没写 `overall_soundscape`；中英混写；结构部分混了中文全角符号 | 补声音字段；结构部分全英文、半角符号 |
| 人呆、木头人 | 写了"面无表情、只说台词"；没有小动作 | 加活人感（见 performance-and-dialogue.md） |
| 演得太夸张 | 直接写情绪词；情绪词堆叠 | 写隐藏目的 + 可见行为 + 先后过程；用 `a fraction`、`a beat late` 这类程度词 |
| 左右站位翻了 | 只在开头说了一次 | 每个镜头陈述一次谁在左、谁在右 |
| 切镜后奔跑方向翻了 | 插入特写里没写方向；机位跳到了动作线另一侧 | 每个切镜写主体往画面哪边动，插入特写也写（`his tail trailing toward the left of the frame`）；机位保持在动作线同一侧（第二轮《纸引》v2 这样写，两个种子方向都没翻；v2 同时改了文体和插入特写的运镜，没有单独拆开） |
| 固定的东西换了位置（水盆、门、柜台） | 只在项目卡或第一镜写了一次 | 它出现的每个镜头都写在画面哪一侧；能挂场景图就挂（《纸引》大殿机位图）。第二轮《纸引》v2 在水盆出现的每个镜头都写，两个种子水盆都没漂 |
| 冲过去的一方先停顿，再被扫开、拦住 | 两个角色的交互放在一个长镜头里（第一轮长镜头交互 4 段里报了 1 段） | 交互放进一个 1.0–1.5 秒的短镜头：从起跳或冲刺的最后一步开始，接触落在这一镜里 |
| 筷子、纸片这类细小物件变形 | 写了折断、掰开、揉搓的动作 | 写成已经完成的状态，直接做下一步；非拍不可就单给插入特写、慢速、只做一下（第二轮《临期》v2 改成拿起已经掰开的筷子，两个种子都没变形） |
| 道具变大、变材质、离开原位 | 后段镜头没再提；描述和参考图冲突 | 有图就把道具定义成 `<Subject N>`，出现的每个镜头写 `matches <Subject N> exactly`，只留状态和位置词（见 performance-and-dialogue.md 第 3 节）；后续镜头写 `the … from Shot 1`，每个出现的镜头都提一次位置 |
| 颜色、光线跨段跳 | 两段光源描述不一样 | 同一场戏同一句底座和光源；用上一段末帧做首帧（有人物时同时挂身份图，见 pipeline-and-settings.md 第 1 节） |
| 整体发糊、细节差 | 设置问题，不是提示词 | 查 pipeline-and-settings.md 第 3 节：分辨率、CFG 1.0、步数 6–8、LoRA 强度 |
| 时长挤、动作赶 | 导播台时长和提示词按的时长不一致 | 两边对齐；切点都小于实际时长 |

## 修改原则

1. **先排除提示词以外的原因**：时长、设置、种子数量。
2. **先删后加**：大部分"乱"是事情太多。先删一个事件或一个镜头，再看。
3. **加的时候只加一句可观察的陈述**，不加 `IMPORTANT`。例：眼神扫得太快 → 在那个镜头里加一句 `Her eyes and head turn together, slowly, toward the door.`
4. **另存新版本**（v2、v3…），在 A/B 表里记下改了什么、结果如何。
