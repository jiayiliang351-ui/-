# zhiyin_ep1_06（8 秒，实际 8.000 秒）

## 简报

写实电影感，雨夜古代纸扎铺的大殿：黑木柱、湿石地、梁上挂白纸莲花灯，左后方铁火盆暖橙光，正后方敞开的大门透进冷蓝雨光。所有角色都是真实的手工纸扎，硬纸、看得见纤维和墨线，只在关节处弯。纸扎小老虎阿糊（白纸身、黑墨条纹、颈上小铜铃、一只琥珀墨眼一只空白纸眼）尾巴尖着着一小簇火，四脚狂奔冲向右侧木凳上的黑铜水盆；纸鹤婆婆（高瘦、长喙、白纸冠、一白一焦黑两只翅膀）从画右跨进来，一翅膀把他扫开，他在湿石地上滚出去；他爬起来再冲，鹤婆一爪踩住他的尾巴尖，火星和黑纸灰炸开，火被踩灭；他被拽住停下，坐在地上回头看烧焦冒烟的尾巴，再看水盆，不再动。没有台词，没有配乐。
