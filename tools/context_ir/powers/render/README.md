# 异能补充版云端对照

两份 JSON 都没有提交生成任务。模型、精度、LoRA、采样器、步数、CFG、分辨率在云端使用同一配置；对照内已固定相同的两个种子。素材为空，不需要 Windows 素材路径。

优先导入 `freeze_acting_ab_4clips.json`：4 段约 60 秒。每个种子先保留全员活动段，再只删这一段；其余提示词字符相同。观察冻结人群是否动、女侠是否完成救人、箭是否落到空地、恢复运动是否清楚。删除会同时改变文字长度，不能把结果全归因于某句话的语义。

需要扩大覆盖时用 `powers_3way_24clips.json`：4 场 × 3 版 × 2 种子，24 段约 288 秒。标题中的“第二版盲写”和“异能补充版盲写”是本轮按对应 skill 新写的测试稿，不是以前已经渲染过的旧片提示词；“官方改写”为本批接口原文，原有配乐和扩写也保留。它是整体对照，不用于单条规则归因。

渲染后记录使用的 JSON、模型/精度、LoRA、采样设置、视频文件和原话反馈。没有看过/听过的项目不填通过。正文与证据记录见 `../analysis/REVIEW_SKILL.md`、`../analysis/VALIDATION.md`。
