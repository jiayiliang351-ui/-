## 导入顺序

建议按 A → B → C 分批生成，每批 8 段：A 念力与元素约 72.5 秒，B 觉醒与时间静止约 72.5 秒，C 能量攻击与一打多约 92.3 秒。合计约 **237.3 秒**（约 4 分钟）；导播台填写秒数合计 236 秒，实际按 24 fps、17k+5 帧取整。

也可以只导入「H3异能测试_全部12情节24段.json」一次生成全部。**整包和三个分包是同一批镜头的两种入口，择一使用，避免重复生成。** 每个情节的种子1、种子2相邻，便于按名字反馈。

全部为纯文字 T2VA、16:9，素材为空、latentRelay 关闭，negativePrompt 为空，配乐 N/A。使用上一轮实际云端配置；填写「生成配置记录.json」。本批没有指定模型、LoRA、分辨率或采样参数，也没有调用 API 或提交生成任务。

## 时间静止与原用例的关系

这批基于原 12 类场景编写新测试提示词，不是官方改写原文对照。八个基础变化和两条攻击类保留原需求核心；时间静止改为明确标出的独立诊断：都市仅两人一杯，不取杯、穿行或恢复；仙侠在单箭冻结后增加右手拨偏，保留左手触发，缩短掌前间距以便操作，不加抱人或恢复。仙侠御剑把“十几个”明确为十二个，一把实体剑与九道光影分别核对。其他连接动作和落点见「用例设计.json」的 adaptation。

这不是只改一句话的因果对照，也不是旧版/官方/新 skill 三版对比；它用于找出当前 skill 在各类异能中的表现。此前通过的单箭纯悬停原稿保留，未拿来替换本批的待测拨箭片段。

## 怎么反馈

使用「反馈表.csv」，按实际片段ID或视频文件名填写。先写看到了什么，再写是否完成了预定情节；画面和声音分列，不用因为某一项通过就把整段填通过。每个情节的两种子分别记，未看或未听的项留空。

重点核对触发先后、能力来源/作用范围、飞行与受力方向、人物和兵器数量、手与道具接触、落点和结束状态。快剪段另看切镜后有没有换边、换人或重新长出武器；声音限制以对应「重点核对」和原文为准。

本批仅做静态格式、结构与原文一致性检查；新提示词全部待出片，不因 lint 通过而填效果通过。两个种子也不足以代表稳定成功率。不会据此自动扩大 skill 规则或追加付费生成。
