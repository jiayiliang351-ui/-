# H3 文戏与异能配套 skill 拆分

完成日期：2026-10-08。任务目录沿用 10 月 7 日开始拆分时的名字。

本轮把已有异能细则和官方样本迁到独立的 `h3-power-fx`，没有重新学习一套格式，也没有新增付费 API 调用或视频生成。格式、对白、摄影和镜头规则继续由主 skill 维护。

## 四个 skill 的分工

| Skill | 负责内容 | 何时使用 |
|---|---|---|
| h3-shot-prompt | 文体、模式格式、合法时长、镜头表、字数、摄影、表演、对白、prompt lint | 写每段 H3 提示词 |
| h3-action-prompt-design | 挂素材、空间方向、门、手和道具、粤语、接力、病症 | 按主题查 |
| h3-director-json-review | 整份导播台 JSON 的审查、批量重写和 JSON lint | 处理整份项目 |
| h3-power-fx | 六类能力的因果、作用范围、静止、光/环境/声音、数量连续性 | 有超自然能力或特效的段 |

普通仙侠客栈对白、古风服装场景、普通徒手打斗不因题材或人数自动加载异能细则。混合剧集只对有能力效果的段使用配套 skill。项目自己的“法力不画特效光”等设定仍在项目卡。

## 本轮改动

- 六类能力细则和 12 条官方 T2VA 原文逐字节迁移到新 skill；没有重新抄写或改写样本。
- 同步主 skill、补充手册、导播台审查及生产流程的真实引用。旧文件路径及原章节标题保留为跳转入口，详细规则只维护一份。
- 保留主规则中的时间静止/定身表演例外、一镜到底例外、保留用户剧情的边界，避免通用审查把异能要求覆盖掉。
- 不新增统一“发出→飞行→命中→消散”要求；不把仙侠风格自动改成新的固定摄影底座。
- 9 个未改内容的原文件在最终交付中复用拆分前原始字节，包括两份检查脚本、摄影、格式、既有范例和项目卡。仓库 7 个 Python 脚本均未改逻辑或正文。

## 效果 embedding 纠错

旧手册把效果文件写成“MiniMax 自带”，本轮改为有条件使用的社区资源。ComfyUI 文档说明，Comfy-Org 托管的 10 个文件来自社区贡献者 silveroxides。[ComfyUI 文档](https://docs.comfy.org/tutorials/video/minimax/minimax-h3-prompt-guide)、[托管目录](https://huggingface.co/Comfy-Org/MiniMax-H3/tree/main/embeddings)、[解析支持变更](https://github.com/Comfy-Org/ComfyUI/pull/15697)。

已检查本地可用源码中的 H3 文本编码调用与 embedding 解析路径，并保存短摘录和哈希；这不是实际编码或效果加载测试。检查到的本地 embedding 目录仅有占位文件；云端未检查，未下载/安装资源。新规则要求使用前检查真实环境和文件，不能凭模型下拉框名称判断，也不能把 bullet time 直接视为完整时间静止。

## 验证结果

- 拆分前独立检索：异能细则已存在，但没有独立 `h3-power-fx` 名称和描述。普通文戏原本已能跳过异能全文，本轮改善的是入口与维护位置，不声称原版每次都会加载全部规则。
- 拆分后独立盲写：10 秒隐形念力、15 秒一镜到底救人各一条；均为 1 镜，lint 均 0 ERROR / 0 WARN。写手未读取官方异能答案。普通仙侠对白路由也正确排除了异能参考。这是一次文本检索/写作测试，不是自动选择命中率统计。
- 四个 skill 的 metadata 验证通过；相对链接与章节锚点可达；12 条完整英文原文与保存的 API 响应逐字核对通过。
- 用最终交付脚本复查两条盲写，并检查导播台 lint 能定位同级主 skill；既有两段 JSON 样例均 0 ERROR / 0 WARN。
- 最终包逐文件核对哈希；只保留各 skill 的实际资源，没有复制第二套检查脚本。独立结构审核及收尾复核详见对应报告。

写手快照保留了 Git 的换行转换；最终包已经复用未改文件的原始字节。后续增加的只是旧章节跳转入口，不影响盲写所用的能力规则。

## 尚未验证的部分

没有导入导播台、排队、渲染、播放或听音，也没有证明独立 skill 会自动被平台重新发现。冻结是否稳定、单臂救人是否穿模、拨箭落点、杯子变形、声源限制和重量感都需要云端出片确认。12 个官方样本仍是文本证据，没有参考图样本。

本轮没有改动已有出片对照 JSON。此前交付的云端测试文件仍可继续使用。

## 安装与回退

四个目录需要同级放置。后续写异能可以明确指定 `$h3-power-fx` 并共同使用主 skill；普通文戏继续使用 `$h3-shot-prompt`。

三个旧 skill 的完整备份、最终安装校验及推送信息见 `交付记录.json`。分享给其它环境时，使用四个安装包的整组压缩包，避免主 skill 与补充入口版本混用。
