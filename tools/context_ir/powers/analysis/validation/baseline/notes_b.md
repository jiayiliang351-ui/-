## 碰到的规则疑问

1. 全局表演固定段要求每个人持续有小动作，与时间冻结里“人群完全停止”冲突。遵循 baseline 的固定段逐字照抄要求，并在事件发生处写箭、人群、灯笼、尘土完全静止。固定段在实际模型中会不会干扰冻结，需要渲染检验；lint 无法判断。
2. 主 skill 建议接触拆成特写或接触前后两镜，但时间冻结简报明确一镜到底。保留一镜，用运镜靠近拨箭，再顺拍单臂抱起、搬运、放稳的完整过程；没有用切镜、瞬移或取消救人规避难点。
3. physics 的一打多骨架要求敌人碎成灰、尽量不演打飞；难点表也建议把打飞缩成踉跄。这与本题完整身体后飞撞车、多人同时压倒不相容。按原简报保留，仍采用该 skill 的快剪、明确方向、近景接触和材质后果写法。
4. 主 skill 的“每镜一条主动作链、其他人只做重复小动作”与剩余打手同时冲来、同时压倒存在冲突。把同步动作写成同一个下压手势引发的集体结果，并拆开能力发起与受力落地两镜，没有减少对手人数或取消同步倒地。
5. skill 没有给时间冻结的专门声场合同。这里写成举手后街声静止，女侠自身脚步、衣料保留，落手后箭声和人群脚步恢复；属于依据画面事件作出的声音实现选择。
