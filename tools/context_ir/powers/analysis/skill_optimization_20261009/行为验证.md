# 行为验证记录

这些是代理对资料检索和写作决策的测试，不是视频渲染。测试按 writing-skills 的旧版基线、候选复测方式进行。

## 旧版基线

独立代理 powers_update_baseline_1009 使用旧版异能 skill 及必要依赖，处理四种请求：低成本四种新能力筛选；定位和保护已认可 C1；外部 V2 的吸收边界；多人受力、环境损伤、御剑接触问题。

结果：多数原有保护条款已被正确理解。代理保留 C1 的局部认可边界，主格式未被 V2 覆盖，能够提出接触与状态保持检查。不能把这些记成旧版失败。

实际暴露的缺口：推荐的四种“新”能力为水杯念力、触摸结霜、短电弧、单箭冻结，均已有测试记录。旧包缺少当前实测索引，导致重复筛选。C1 定位依赖测试任务额外给出的外部 JSON 路径，旧包不能独立检索该原稿。

据此补充实测索引和精确 C1 原稿，另外将用户反馈中的动作检查整理为按需参考文件，不改共享规则。

## 候选复测

由新的独立代理 power_candidate_check_1009 读取更新后的 skill，处理同类四请求；不提供 C1 外部 JSON 路径或预期答案。另写8秒雷击固定铁杆的新稿，运行原检查器。结果在完成后追加。

## 静态验证边界

技能格式、引用路径、精确原文及文件保护检查见静态验证和部署校验记录。历史 C1 有三个 lint ERROR：缺 Shot 标记、DO NOT、NEVER；原文保留并披露，没有修改检查器绕过。新写候选须单独符合现行格式。


## 候选结果

独立代理正确区分已有念力、电弧、结霜、箭冻结与待筛选的火焰、重力、护盾、裂缝；能从包内定位C1的ID、seed和局部时机认可，不依赖外部路径。外部模板未覆盖文戏规则；群体受力修正保留原剧情，能区分缴械、惊退与命中。

另写的雷击固定铁杆候选：原lint结果为T2VA、1镜、8秒、323词、无对白，OK，无ERROR/WARN。主代理复跑确认。仅静态验证，无视频提交。

审查提出主skill多种子/单变量与首筛单种子/整体候选的适用歧义，已在筛选参考开头明确：首筛不判通过，多种子用于复现，整体候选不作单变量因果实验，普通文戏不变。该补充由主代理复核；独立代理追加复核因额度限制未完成，不记录为二次独立通过。

另两项既有主skill措辞风险（风险表中的减负示例、结尾停顿解释）未修改原文；异能配套已明确保留关键结果、人数及持续动作，不把碎灰替代真人或强制停顿。没有将旧主文件问题伪称本次已修复。
