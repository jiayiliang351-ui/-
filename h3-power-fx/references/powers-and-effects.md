# 异能、元素与时间静止

用于都市异能、仙侠、念力、元素变化、觉醒、时间静止、御剑和一打多。仍按主 skill 的英文文体、格式和本地已验证的剪辑写法输出。

**证据边界**：`official-powers-calibration.md` 收录 12 条官方 T2VA 改写，每类两条、每个需求只有一次采样，尚未渲染。下面用于保护简报、消除规则冲突，并提供候选写法；不表示模型已经能稳定完成这些效果，不修改既有实测的镜头表、采样设置或防串词规则。没有参考图样本，不能据此更改 Ref2VA 的主体定义和保留标记。

现有渲染证据见[实测索引](render-evidence.md)：单支飞箭冻结两个种子获整体认可，扩展测试含局部亮点和失败，C1另有一个种子的时机认可。这些独立于12条官方改写，不将局部认可扩成全场冻结或完整打斗已验证。

## 1. 先保留能力，再降低镜头难度

写之前在提示词之外记下：能力由谁触发、作用对象和范围、可见或不可见、主结果、结束状态、人物/武器数量、声音限制、是否一镜到底。简报已有的照简报；缺的只补连接动作所需的细节，不新增能力或后果。

- 用户指定的打飞、撞柱、断刀、抱走孩子、多人压倒不能自动换成踉跄、碎灰或省略。风险先用更清楚的景别、较短的关键接触、分离起因与后果来处理；无法承载时在提示词之外说明风险和替代方案，不把替代剧情当原需求交付。
- 多次交锋才按快动作表；一个物件浮起、一次结霜、连续蓄能属于变化过程，不为凑快剪镜头数加动作。用户明确指定一镜到底，就用连续跟拍、横摇或推近串起事件，不能为了接触特写偷偷切镜。
- 动作链的规划和接触、群体受力、损坏保持细查[动作编排](action-design.md)。规划里的完整状态账用于发现遗漏，正文只保留当前镜头看得见、需要追踪的状态。
- 用户限定“只有某些声音”时，检查整份声音设计，包括衣料、呼吸、拟音和音乐；默认底噪也受此限制。无台词就不新增对白；未要求配乐的剧集段按主 skill 写 `N/A`。

## 2. 按能力选择因果链

把下面的项目写成连续描述，不输出标签清单。各阶段只按简报选用，不补没有指定的松劲、落地或消散；不必每种能力都写手掌光球或飞行轨迹。

| 能力 | 要交代的变化 | 候选参照 |
|---|---|---|
| 能量波、剑气 | 按简报直接发出或先聚能 → 沿指定方向到达 → 命中具体部位/物件 → 受力后果 → 简报要求的熄灭或余波；快速反击不默认插入蓄能等待 | `blast_urban`、`blast_xianxia` |
| 不发光的念力 | 施力者的注视或手势 → 目标先颤动/滑移/离地 → 悬浮或定向移动 → 放松后落定；物体保留原材质与现场照明 | `telekinesis_urban`、`telekinesis_xianxia` |
| 结霜、电弧 | 从接触点或指间开始 → 变化蔓延/增强 → 材质、光或发丝的相关反应 → 保留结冰或熄灭后的状态 | `element_urban`、`element_xianxia` |
| 觉醒、局部领域 | 身体触发 → 能力影响的范围与对象 → 环境/对手的指定反应 → 按简报维持或收回 | `awaken_urban`、`awaken_xianxia` |
| 时间静止 | 可见触发 → 指定元素在运动中定住 → 获准移动者完成动作 → 保持到结尾；仅简报要求恢复时再写解除与原运动接续 | `timestop_urban`、`timestop_xianxia` |
| 一打多、御剑 | 每次交锋的起因和结果 → 已倒地/仍行动者的状态 → 兵器实体与剑影变化 → 最终人数、武器归位和余波 | `onevsmany_urban`、`onevsmany_xianxia` |

**发光与隐形力量分开写。** 发光能力可用颜色落在附近脸、衣服、墙面上的变化交代强弱；熄灭后回到原场景光。隐形念力用目标运动、衣袖、风、叶、水或灰尘表现，只选简报已有的对象；不用 `no glowing effects` 反复点名不存在的光，也不另加光环或光束。环境反应够说明能力即可，不堆多层特效。

**来源不一定在手上，终点不一定是消散。** 灵气可来自周围空气；时间静止没有抛射物轨迹。霜留在杯壁、裂纹留在石台；局部雨滴若简报没有恢复，就保持悬停，不擅自补雨恢复。只有简报要求收回/熄灭时才写消散。能力关闭也不会自动修复已损坏的物件。

**念力开门仍需因果。** 普通戏的“人、手、接触点”用来防无缘无故的自行动作；用户指定异能时，保留手势 → 叶流或不可见力量作用 → 门向指定方向晃开 → 停在哪，不补开门的人。例如 `telekinesis_xianxia` 中，手指指向右侧院门后，叶流撞门使门打开。手势与物体变化是可见证据，力量本身可以不可见。

### 新能力按可见变化选择检查，不宣称已验证

| 表现方式 | 可扩展的能力 | 先检查什么 |
|---|---|---|
| 沿表面传播 | 结霜、地面火焰、材质变化 | 起点、传播方向、表面贴合、变化前沿与最终覆盖；火墙属于后续成形，不凭空换位置 |
| 从源头到目标 | 雷击、能量波、飞剑 | 路径、先后、可见命中、目标反应；雷电新命中场景不能用指间电弧反馈代替 |
| 隔空施力 | 念力、重力、金属控制 | 原有支撑、运动方向、变形或位移、落点；漂浮后归位与突然下压不是同一结果 |
| 停止与保持 | 单物冻结、局部领域、多人时停 | 冻结前运动、触发、停点、获准移动者、结束；首帧已悬停不证明捕获下落成立 |
| 边界形成与碰撞 | 护盾、空间裂缝 | 边界出现的位置、材质/透光、若有攻击则接触与阻挡；只展示裂缝时不额外添加穿越或伤害 |

共用的是观察方法，不是这些能力已有同等成功率。每段选一个核心变化及必要后果；镜头中的光、衣物和道具反应服务于它。可见结果也可以是结霜、悬停或边界成形，不强迫每种异能都爆炸或毁坏物体。

## 3. 时间静止的动作与声音

- 区分世界静止与局部定身。天台觉醒只定住身边雨滴，并不自动冻住三个打手；他们仍按简报后退。全场时间静止才定住路人、箭、灯笼、尘土等指定对象。
- 时间静止、集体定身段不加全局表演段 `Nobody stands idle … Every character is always occupied …`，不另造一段相反的固定规则。逐个写受限姿态与获准的动作；完全时间静止的对象恢复后才续上原运动，普通定身仍按简报决定是否能眨眼、呼吸或说话。
- 被移动的冻结物有局部状态变化：被拨偏的箭保持新角度，手离开后仍悬停；被取下的杯子跟随主角的手；恢复后从更新的位置继续。不能把全场都写成随主角行动。
- 涉及手的占用要从触发走到解除：哪只手维持手势、哪只手拨箭、怎么腾手抱孩子、放下孩子后怎样解除。无需为了修手势改掉“抬手定住、放手恢复”的用户设定。
- 声音按“正常 → 静止期间允许的声源 → 恢复”写成连续段落。若指定静止时只有脚步声，期间不加指响、衣料、呼吸、碰杯声或持续配乐；解除触发若有可听声音，放在静止结束边界。仙侠简报没有相同限制时，不把都市版本的声音约定强套过去。
- 一镜到底中的救人、递杯是高风险动作。保留镜头连续性，靠跟拍接近手部、留出操作空间减负；把风险列在提示词外，不声称已解决穿模。

## 4. 多人、兵器与受力连续性

- 在规划里做人数账，提示词里只写可见状态。例如六名打手先倒下一人、再撞车一人，剩四人冲来；最后仍是这六人的落点，不新增一圈替身。只有主攻击链是主动动作，群体受力是同一次攻击的结果，不算必须删除的第二条主动作链。
- 给需要跨镜追踪的敌人一个简短区别，例如持棍者、持刀者；不为每个杂兵补人物传记。已倒地的人保持结果状态，不在下一镜重新冲来。
- 一把飞剑与九道剑影分清：出鞘的实体剑 → 指定的剑影变化 → 按简报回鞘，避免无意写出九把各自独立的实体兵器。分化数量和最终数量按简报，不添加新武器。
- 能量的运动方向、受击者位移、撞击位置和碎屑方向连起来；后果在足够宽的景别内可见。接触短镜头可沿用本地快剪经验，但原 12 条官方文本不能证明打飞、多人物理或一镜救人的成功率。

## 5. 不照学与出片验收

官方原文也会加戏。查 `official-powers-calibration.md` 开头的逐例偏差：额外配乐、扩大声源、未交代杯子落点、左手触发与抱孩子的占用需要澄清、拨偏箭的轨迹与最终落点需要核对，以及遗漏镜头标记。不要用 lint 无 ERROR 或“更像官方”代替简报核对。

写完跑原有lint，再人工查能力、人数、手、轨迹、作用范围、声源和结束状态。现有结果逐项见[实测索引](render-evidence.md)，未报告的画面/声音留空。新能力可以先按[筛选与迭代](calibration-workflow.md)小批首筛；要评价重复性再补种子，要归因于某一改动则保持配置和seed对照。格式通过、代理试写通过均不能替代渲染验收，不把整体收益归给单条规则。
