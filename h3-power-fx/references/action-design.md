# 异能动作：接触、受力与结果保持

用于攻击、拦截、拨物、群体受力和御剑。下面是编排与审查方法，依据已报告的失败定位检查点；不是保证成功的新咒语，不改变主skill的摄影、对白或镜头预算。

## 1. 先列一条可看见的动作链

提示词外写：**初态 → 威胁或触发 → 能力作用/接触 → 对象变化 → 落定与保留状态**。

| 检查项 | 写作前回答 |
|---|---|
| 初态 | 谁在哪，离目标多远，手/兵器在何处，物体由什么支撑？ |
| 时机 | 攻击已开始还是正在准备？反击发生在攻击前、接触时还是接触后？ |
| 作用 | 能量/兵器/不可见力如何抵达哪个对象、哪个部位？ |
| 受力 | 对象先有什么反应，再往哪里移动/变形，如何到达落点？ |
| 结束 | 光效如何结束，损伤/霜/倒地/冻结哪些继续保留？ |

一次反击包含施力者动作和对手反应，仍是一条主动作链。不要为了“一人一个动作”把双方必要交互拆没；也不把起手、蓄能、冲刺、命中、转身炫技等所有事件挤在同一镜。

## 2. 攻击时机：避免到了身前才开始准备

- 先判断是否需要长距离接近。用户允许从交锋处开始时，可从攻击即将发生的姿态开场；若指定完整冲刺，保留冲刺，不能静默删掉。
- 快速反击把触发与受力写成同一节拍：对方最后一步/挥击准备 → 防守方施力 → 对方相应部位后震。若需要蓄能，安排在接触距离到来前，并让对方的动作持续推进。
- 必须看清的接触可按主skill用短镜头呈现；连续变化或明确一镜到底保留连续机位。用户已认可的一镜版本不为统一镜头数强拆。
- 毫秒计划可供内部排布，不能保证模型按点执行。新稿按主skill表达可见先后；[C1旧稿](rendered-palm-counter.md)的时间标签是历史文本，不构成有效原因的证明。
- 为强调连续而增加“先站稳等一下”可能改变进攻逻辑。静态对白需要的起止缓冲不自动用于冲刺、接触和追逐。

## 3. 强化威力先明确改变哪种可见结果

区分：**亮度/规模、身体受力、位移速度、碰撞破坏、声音**。增加光亮不等于打击更重，人物后退不等于离地击飞。

用户要强化已认可镜头时，先锁住原攻击时机，选最影响使用的一个结果块改。例如只调整受击后身体与位移，或只调整撞击时的材质反馈；若整体重排以追求成片，可改多个因素，但记录为整体候选，不事后归因于单句。

受力写到可见部位：胸口/肩膀反应、重心变化、脚步或离地、移动方向、碰撞与落地。按简报保留击飞，不能用踉跄冒充；也不为“增强”擅自加爆炸、死亡或血肉变化。

光效选少量相关环境反应：脸侧、衣袖或近墙的反光随光源变化；隐形能力不默认加光。能力结束后恢复现场光，但断裂、凹痕、冰层等按剧情保留。

## 4. 手、端向和道具状态

- 需要精确手势时写可见指位和接触关系，同时核对景别能否辨认。用户指定双指并拢、拇指贴无名指时保留；不把这套手势规定给所有法术。
- 抓点区分箭头、木杆中部、羽尾；握柄与握剑身不同。另一只手若维持法术，明确其占用，避免抓物时又承担第二动作。
- 箭/剑先定义两端及领飞方向。终角与停点单独看：向下45度不等于垂直向下；能悬停不等于抓点、方向或速度都对。
- 飞剑完全离鞘后才转向；返程交代剑尖与鞘口，按简报回到原鞘。悬在指旁不等于必须用手握住剑身。
- 新增细节只解决当前问题，避免把手部写成一串难以同时展示的动作。

## 5. 跨镜状态账

在规划表中记“变化前 → 变化后 → 后续出现时的状态”，正文在相关镜头陈述可见结果。

- 断刀：哪段落地、哪段仍在手中；后镜不回到完整刀。断成两段时，握柄一段包含残余刀身，不另凭空多断一节。
- 撞车/撞柱：损伤位置与撞点一致，后续再次入画仍有凹痕/裂纹；人落地不会自动修复环境。
- 拨箭：转角后松手，检查新角度是否保持；初次冻结和后续操作分别验收。
- 群体：倒下者位置和仍行动者人数逐次更新；画面再切回来时不能补一圈新敌人。
- 一股能量连续击中两个目标时，预先安排两目标与路径；跟拍下坠人物再切远处树枝，不能让能量在新地点凭空重启。必要时拆为可见的路径段，保留用户要求的两个结果。

## 6. 群体和御剑：特效出现不代替命中

“双掌下压、四人膝先着地”可能呈现跪拜；用户要击飞时应设计离地/位移/落地。对照时明确这是动作编排改变，不是仅修模型错误。

飞剑先抵达兵刃/目标，接触或清楚的隔空施力后，对手才有对应反应。惊吓退却可以由目击触发，不伪装成已经遭受物理命中。实体剑与剑影分别记数量和用途：绕转可以是展示，若要攻击还需写实际攻击对象与后果。

多人复杂场景可先单目标验证接触，再增加参与者；诊断另命名，不能把一人缴械记为一打十二已通过。需要原人数和结果的正式稿仍按用户要求完成。

## 7. 时间静止特别核对

将“触发可见、运动中捕获、停点保持、人物冻结、局部操作、解除恢复”分别观察，只测试简报包含的阶段。

- 首帧已有悬浮物只说明保持条件，不说明能把下落物捕获。
- 杯子下落后回升属于轨迹改变，不算下落途中定住。
- 单箭冻结、局部雨滴静止、多人同步冻结是不同范围；任何一项失败或通过都不能覆盖其他项。
- 有人冻结时，默认呼吸、发丝、衣物微动等“活人感”不能不加区别地施给被冻结者。只冻结雨滴而人仍可动时，按实际范围保留表演。
- 接触操作增加难度，先判断抓点与手占用，不为修手而改掉用户设定的维持/解除方式。声音按对应阶段允许的声源安排。
