# H3 异能与特效配套手册

配合 **`h3-shot-prompt`** 使用。它负责格式、合法时长、镜头表、字数预算、摄影底座、表演、对白和 lint；本 skill 只补能力与特效的条件写法。不要复制另一套三段式、六段式、对白或检查脚本。

## 入口与依赖

- 先读同级的 [h3-shot-prompt](../h3-shot-prompt/SKILL.md)，并按它读取模式规范和对应项目卡。已读过则直接沿用。
- 异能段读 [能力与特效细则](references/powers-and-effects.md)，按其中六类查需要的部分。普通文戏不读这些细则；混合项目只对有特效的段启用。
- 挂素材、空间、门、手和接力需要时查 [h3-action-prompt-design](../h3-action-prompt-design/SKILL.md)。整份导播台 JSON 用 [h3-director-json-review](../h3-director-json-review/SKILL.md)，仍只改用户授权的字段。
- 主 skill 缺失时说明共享依赖缺失；不临时发明另一套格式。配套 skill 没有自己的 API 调用或渲染权限。

## 写作与审查

1. 依主 skill 确定时长、模式、项目设定和原台词。把触发者、对象与范围、可见性、关键结果、结束状态、人数/武器数、声音限制、一镜到底要求记在提示词外。
2. 按[细则第 2 节](references/powers-and-effects.md#2-按能力选择因果链)选因果链：能量波/剑气、隐形念力、元素、觉醒/领域、时间静止、一打多/御剑。只写简报需要的阶段，不强套“发出→飞行→命中→消散”；霜与裂纹可以留下。
3. 难动作先用景别、运镜和节拍减负，保留指定结果。一个物件持续变化不自动套快剪；明确一镜到底时保持连续。时间静止按细则第 3 节处理可动者、手占用和声源，不补要求全员持续活动的表演段。
4. 依主 skill 输出英文连续描述，台词逐字保留。格式、镜头与对白规则由主 skill 维护；本 skill 的条件例外和项目设定一起适用。若仍有无法同时满足的要求，在提示词外说明，不静默改剧情。
5. 从同级 `h3-shot-prompt` 定位原有 `scripts/lint_prompt.py`，运行 `python <h3-shot-prompt目录>/scripts/lint_prompt.py <提示词文件> --seconds <秒数>`；修 ERROR、核对 WARN，再按细则核对能力、手、人数、方向、范围、声音与结束状态。整份 JSON 继续用导播台审查 skill 的 `scripts/lint_json.py`。

## 都市与仙侠的风格

两者共用主 skill 的摄影与表演规则；项目卡已有画风开头时按项目卡，避免叠加互相冲突的底座。都市根据简报写现实场所、服装、现场光和材质反馈；仙侠根据简报写服装、地形、建筑、月光/日光等现场条件。不凭“仙侠”一词新增灵气、发光、古筝配乐或夸张表演。

新的调色或摄影底座属于待测选项，不称为已经验证的仙侠标准。项目自己的“法力不画特效光”等设定仍留在项目卡，不能扩成通用禁令。

## 参照与证据

- [12 条官方 T2VA 原文](references/official-powers-calibration.md)：按案例 ID 找最接近的一条，先读开头的偏差说明；无需每次通读全部样本。它们教文体，不能覆盖用户的剧情、人数或声音限制。
- 当前新增细则通过文本核对与盲写检查，尚无异能渲染结果；没有参考图样本。不称“本地验证有效”，不据此缩减已验证的快剪写法或改 Ref2VA 标记。
- [效果 embedding](references/effects-embeddings.md)：仅在用户要求使用效果文件时读取。它是可选外部资源，不能靠文件名认定当前环境已支持、已安装或效果已验证。
- 出片检查与对照方法沿用细则第 5 节和主 skill 的生产流程；不要为“继续学习”自行追加付费 API 调用。
